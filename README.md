# Memorius (native Android: XML + Java)

Build the APK in the cloud: upload this whole folder (keep the hidden .github folder) to a GitHub repo,
open the Actions tab, run "Build APK", download the "memorius-apk" artifact, unzip, install app-debug.apk.

Screens: app/src/main/res/layout/*.xml   Languages: res/values (en-GB), values-in (Indonesian), values-fr (French)
Code: app/src/main/java/com/memorius/app/
